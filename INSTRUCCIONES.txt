FIDNESSRUTINAS - INSTRUCCIONES DE USO
====================================

REQUISITOS
----------
1. Apache NetBeans.
2. JDK 26.
3. MySQL Server en ejecucion.
4. MySQL Workbench o un cliente equivalente para ejecutar archivos SQL.

ABRIR EL PROYECTO EN NETBEANS
-----------------------------
1. Descomprima FidnessRutinas-Proyecto-Completo.zip.
2. Abra NetBeans.
3. Seleccione File > Open Project.
4. Seleccione la carpeta FidnessRutinas que contiene build.xml, nbproject
   y src. No seleccione solamente la carpeta src.
5. NetBeans debe mostrar el proyecto FidnessRutinas en el panel Projects.

PREPARAR MYSQL
--------------
El archivo SQL crea la base de datos y sus tablas. El archivo
database.properties le indica al programa como conectarse al MySQL
instalado en esta computadora. Por eso ambos pasos son necesarios.

El ZIP no contiene una copia de la base de datos instalada en la
computadora del estudiante ni archivos internos de MySQL. schema.sql se
incluye porque contiene solamente las instrucciones necesarias para que
el profesor pueda crear en su propio MySQL la base fidness_rutinas, sus
cuatro tablas y sus relaciones. Los usuarios y ejercicios iniciales los
crea la aplicacion durante el primer arranque si las tablas estan vacias.

1. Abra MySQL Workbench e ingrese a su conexion local.
2. Seleccione File > Open SQL Script.
3. En la ventana para seleccionar el archivo, entre a la carpeta del
   proyecto descomprimido y abra esta ruta exacta:

   FidnessRutinas\database\schema.sql

   Presione el boton del rayo para ejecutar todo el archivo.
4. En el panel Schemas, actualice la lista y compruebe que aparezca:

   fidness_rutinas

5. Abra en el Explorador de Windows esta carpeta incluida en el ZIP:

   FidnessRutinas\nbproject\private

6. Dentro de private ya se encuentra el archivo:

   FidnessRutinas\nbproject\private\database.properties.example

7. Haga una copia de database.properties.example en esa misma carpeta.
8. Cambie el nombre de la copia para que su ruta final sea exactamente:

   FidnessRutinas\nbproject\private\database.properties

9. Abra database.properties con un editor de texto. Su contenido debe
   quedar similar al siguiente ejemplo:

   url=jdbc:mysql://127.0.0.1:3306/fidness_rutinas?serverTimezone=America/Costa_Rica&useSSL=false&allowPublicKeyRetrieval=true
   usuario=root
   contrasena=SU_CONTRASENA_DE_MYSQL

La copia es necesaria porque database.properties.example es una plantilla
sin credenciales privadas. El programa busca especificamente el archivo
llamado database.properties. Cada computadora debe crear su propia copia
con las credenciales de su instalacion local de MySQL.

10. Sustituya root y SU_CONTRASENA_DE_MYSQL por el mismo usuario y
    contrasena que utiliza para ingresar a MySQL Workbench. Normalmente no
    es necesario cambiar la linea url.
11. Guarde el archivo y confirme que su nombre no termine en .txt.

Ejemplo si en MySQL Workbench se utiliza el usuario root y la contrasena
ClaveMysql123:

   usuario=root
   contrasena=ClaveMysql123

Ejemplo si el usuario root de MySQL no tiene contrasena:

   usuario=root
   contrasena=

Los usuarios heiner/1234 y admin/admin pertenecen a FidnessRutinas. No se
deben escribir como credenciales de MySQL en database.properties.

IMPORTANTE: schema.sql no puede crear database.properties porque el
usuario y la contrasena de MySQL son diferentes en cada computadora. El
archivo database.properties creado localmente tampoco debe enviarse ni
subirse al repositorio.

EJECUTAR DESDE NETBEANS
-----------------------
1. Presione Clean and Build Project.
2. Cuando aparezca BUILD SUCCESSFUL, presione Run Project.
3. La aplicacion inicia el servidor local en el puerto 5050 y luego
   muestra la ventana de ingreso.

EJECUTAR EL PAQUETE COMPILADO
-----------------------------
1. Utilice la misma carpeta FidnessRutinas extraida del ZIP completo.
2. Complete primero todos los pasos de la seccion PREPARAR MYSQL.
3. Abra una terminal en la carpeta FidnessRutinas. Es la carpeta que
   contiene dist, database, nbproject y src.
4. Ejecute:

   java -jar dist/FidnessRutinas.jar

USUARIOS DE PRUEBA
------------------
Usuario regular:
  usuario: heiner
  contrasena: 1234

Usuario administrador:
  usuario: admin
  contrasena: admin

PRUEBA COMPLETA DEL PROGRAMA
----------------------------
1. Ejecute el proyecto desde NetBeans o con el JAR. Debe aparecer la
   ventana FidnessRutinas - Ingreso y el servidor debe utilizar el puerto
   5050.
2. Intente ingresar con datos incorrectos y compruebe que la aplicacion
   rechace el acceso.
3. Ingrese con heiner y 1234. Debe aparecer el catalogo de ejercicios.
4. Seleccione un ejercicio de la tabla y compruebe que aparezca su detalle.
5. Seleccione una categoria, presione Filtrar y compruebe que la tabla
   muestre solamente esa categoria. Presione Ver todos para recuperar el
   catalogo completo.
6. Seleccione un ejercicio y presione Agregar a rutina. Debe aparecer en
   la lista Ejercicios de la rutina.
7. Intente agregar el mismo ejercicio otra vez. La aplicacion debe impedir
   el duplicado.
8. Agregue otro ejercicio, seleccionelo en la lista de la rutina y presione
   Eliminar seleccionado. Debe desaparecer de la rutina.
9. Deje al menos un ejercicio agregado y presione Exportar rutina. Guarde
   el archivo TXT y abralo para comprobar que contiene el resumen.
10. Compruebe que el usuario heiner no tenga el boton Registrar ejercicio.
11. Cierre la aplicacion, ejecutela de nuevo e ingrese con heiner y 1234.
    El ejercicio dejado en la rutina debe continuar guardado.
12. Cierre la aplicacion, ejecutela nuevamente e ingrese con admin y admin.
    Debe aparecer el boton Registrar ejercicio.
13. Presione Registrar ejercicio y registre un ejercicio de fuerza con un
    nombre nuevo, descripcion, categoria, dificultad, series y
    repeticiones. Al guardar, debe aparecer en la tabla.
14. Registre un ejercicio de tipo cardio. El formulario debe solicitar
    minutos y asignar la categoria CARDIO.
15. Seleccione los ejercicios registrados y compruebe sus detalles.

PRUEBA CLIENTE-SERVIDOR
-----------------------
1. Mantenga abierta una primera instancia de FidnessRutinas.
2. Abra otra terminal en la carpeta FidnessRutinas y ejecute de nuevo:

   java -jar dist/FidnessRutinas.jar

3. La segunda instancia debe utilizar el servidor que ya escucha en el
   puerto 5050 y mostrar otra ventana de ingreso.
4. Ingrese con heiner en una ventana y con admin en la otra. Compruebe que
   ambas puedan consultar el catalogo y sus respectivas rutinas.
5. Cierre primero la segunda instancia y luego la primera.

COMPROBAR LOS DATOS EN MYSQL
----------------------------
En MySQL Workbench ejecute estas consultas despues de las pruebas:

   USE fidness_rutinas;
   SELECT * FROM usuario;
   SELECT * FROM ejercicio;
   SELECT * FROM rutina;
   SELECT * FROM rutina_ejercicio;

Deben aparecer los usuarios iniciales, los ejercicios registrados y las
relaciones de las rutinas utilizadas durante la prueba.

FUNCIONES PRINCIPALES
---------------------
- Consultar y filtrar ejercicios.
- Ver el detalle de cada ejercicio.
- Agregar y eliminar ejercicios de la rutina.
- Exportar el resumen de la rutina a un archivo TXT.
- Registrar ejercicios con el usuario administrador.
- Conservar el catalogo y las rutinas en MySQL.

NOTAS
-----
- El conector MySQL ya se incluye en lib y dist/lib.
- La aplicacion crea los datos iniciales si las tablas estan vacias.
- Las credenciales privadas de MySQL no se incluyen en el repositorio.
- Si el puerto 5050 esta ocupado, cierre la otra instancia antes de iniciar.
