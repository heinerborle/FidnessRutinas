FIDNESSRUTINAS - INSTRUCCIONES DE USO
====================================

ARCHIVOS PREPARADOS PARA SUBIR
------------------------------
Las siguientes rutas parten de la carpeta Entrega Final de este trabajo:

1. Documento escrito:

   salida/Proyecto FidnessRutinas - Heiner Borbon Leon.docx

2. Proyecto completo para abrir en NetBeans:

   salida/codigo/FidnessRutinas-Proyecto-NetBeans.zip

3. Paquete ya compilado para ejecutar fuera de NetBeans:

   salida/codigo/FidnessRutinas-Ejecutable.zip

El archivo principal de codigo que debe subirse es
FidnessRutinas-Proyecto-NetBeans.zip. El ZIP ejecutable se puede adjuntar
como apoyo para facilitar la revision. INSTRUCCIONES.txt ya esta incluido
dentro de ambos ZIP.

No se debe subir nbproject/private/database.properties porque contiene las
credenciales privadas de MySQL de la computadora donde se ejecuta el
programa. Cada persona crea su propia copia siguiendo esta guia.

COMO INTERPRETAR LAS RUTAS DE ESTA GUIA
---------------------------------------
Todas las rutas indicadas desde la seccion REQUISITOS parten de la carpeta
principal del proyecto descomprimido. Por ejemplo:

   database/schema.sql

significa entrar primero a FidnessRutinas, despues a database y finalmente
abrir schema.sql. En la copia de trabajo de este equipo, la ruta es:

   codigo/FidnessRutinas/database/schema.sql

Al descomprimir FidnessRutinas-Proyecto-NetBeans.zip se obtiene esta
estructura:

   FidnessRutinas/
   |-- build.xml
   |-- manifest.mf
   |-- INSTRUCCIONES.txt
   |-- database.properties.example
   |-- database/
   |   `-- schema.sql
   |-- lib/
   |   `-- mysql-connector-j-9.7.0.jar
   |-- nbproject/
   |   |-- project.xml
   |   `-- project.properties
   `-- src/
       `-- fidnessrutinas/ (codigo fuente Java)

El ZIP de NetBeans contiene el codigo fuente y es el que se abre con
File > Open Project. El ZIP ejecutable contiene el JAR ya compilado y se
utiliza solamente con el comando java -jar explicado mas adelante.

REQUISITOS
----------
1. Apache NetBeans.
2. JDK 26.
3. MySQL Server en ejecución.

ABRIR EL PROYECTO EN NETBEANS
-----------------------------
1. Descomprima FidnessRutinas-Proyecto-NetBeans.zip.
2. Abra NetBeans.
3. Seleccione File > Open Project.
4. Seleccione la carpeta FidnessRutinas que contiene build.xml, nbproject
   y src. No seleccione solamente la carpeta src.
5. NetBeans debe mostrar el proyecto FidnessRutinas en el panel Projects.

PREPARAR MYSQL
--------------
El archivo SQL crea la base de datos y sus tablas. El archivo
database.properties le indica al programa como conectarse al MySQL
instalado en esta computadora. Por eso ambos pasos son necesarios.

1. Abra MySQL Workbench e ingrese a su conexion local.
2. Seleccione File > Open SQL Script.
3. Abra database/schema.sql y presione el boton del rayo para ejecutarlo.
4. En el panel Schemas, actualice la lista y compruebe que aparezca:

   fidness_rutinas

5. Localice database.properties.example en la carpeta principal del
   proyecto.
6. Si la carpeta nbproject/private no existe, creela.
7. Copie database.properties.example dentro de nbproject/private y cambie
   el nombre de la copia a:

   database.properties

8. Abra database.properties con un editor de texto. Su contenido debe
   quedar similar al siguiente ejemplo:

   url=jdbc:mysql://127.0.0.1:3306/fidness_rutinas?serverTimezone=America/Costa_Rica&useSSL=false&allowPublicKeyRetrieval=true
   usuario=root
   contrasena=SU_CONTRASENA_DE_MYSQL

9. Sustituya root y SU_CONTRASENA_DE_MYSQL por el mismo usuario y
   contrasena que utiliza para ingresar a MySQL Workbench. Guarde el
   archivo y confirme que no termine en .txt.

IMPORTANTE: schema.sql no puede crear database.properties porque el
usuario y la contrasena de MySQL son diferentes en cada computadora.

EJECUTAR DESDE NETBEANS
-----------------------
1. Presione Clean and Build Project.
2. Cuando aparezca BUILD SUCCESSFUL, presione Run Project.
3. La aplicacion inicia el servidor local en el puerto 5050 y luego
   muestra la ventana de ingreso.

EJECUTAR EL PAQUETE COMPILADO
-----------------------------
1. Descomprima FidnessRutinas-Ejecutable.zip.
2. Ejecute database/schema.sql siguiendo los pasos anteriores.
3. Entre a nbproject/private.
4. Cambie el nombre de database.properties.example a database.properties.
5. Abra el archivo, escriba sus credenciales locales de MySQL y guardelo.
6. Abra una terminal en la carpeta FidnessRutinas-Ejecutable.
7. Ejecute:

   java -jar dist/FidnessRutinas.jar

FUNCIONES PRINCIPALES
---------------------
- Consultar y filtrar ejercicios.
- Ver el detalle de cada ejercicio.
- Agregar y eliminar ejercicios de la rutina.
- Exportar el resumen de la rutina a un archivo TXT.
- Registrar ejercicios con el usuario administrador.
- Conservar el catalogo y las rutinas en MySQL.

NOTAS
-----
- El conector MySQL ya se incluye en lib y dist/lib.
- La aplicacion crea los datos iniciales si las tablas estan vacias.
- Las credenciales privadas de MySQL no se incluyen en el repositorio.
- Si el puerto 5050 esta ocupado, cierre la otra instancia antes de iniciar.
