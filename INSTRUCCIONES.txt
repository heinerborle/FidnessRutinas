FIDNESSRUTINAS - INSTRUCCIONES DE USO
====================================

REQUISITOS
----------
1. Apache NetBeans.
2. JDK 26.
3. MySQL Server en ejecución.

ABRIR EL PROYECTO EN NETBEANS
-----------------------------
1. Descomprima FidnessRutinas-Proyecto-Completo.zip.
2. Abra NetBeans.
3. Seleccione File > Open Project.
4. Seleccione la carpeta FidnessRutinas que contiene build.xml, nbproject
   y src. No seleccione solamente la carpeta src.
5. NetBeans debe mostrar el proyecto FidnessRutinas en el panel Projects.

PREPARAR MYSQL
--------------
El archivo SQL crea la base de datos y sus tablas. El archivo
database.properties le indica al programa como conectarse al MySQL
instalado en esta computadora. Por eso ambos pasos son necesarios.

1. Abra MySQL Workbench e ingrese a su conexion local.
2. Seleccione File > Open SQL Script.
3. En la ventana para seleccionar el archivo, entre a la carpeta del
   proyecto descomprimido y abra esta ruta exacta:

   FidnessRutinas\database\schema.sql

   Presione el boton del rayo para ejecutar todo el archivo.
4. En el panel Schemas, actualice la lista y compruebe que aparezca:

   fidness_rutinas

5. Abra en el Explorador de Windows esta carpeta incluida en el ZIP:

   FidnessRutinas\nbproject\private

6. Dentro de private ya se encuentra el archivo:

   FidnessRutinas\nbproject\private\database.properties.example

7. Haga una copia de database.properties.example en esa misma carpeta.
8. Cambie el nombre de la copia para que su ruta final sea exactamente:

   FidnessRutinas\nbproject\private\database.properties

9. Abra database.properties con un editor de texto. Su contenido debe
   quedar similar al siguiente ejemplo:

   url=jdbc:mysql://127.0.0.1:3306/fidness_rutinas?serverTimezone=America/Costa_Rica&useSSL=false&allowPublicKeyRetrieval=true
   usuario=root
   contrasena=SU_CONTRASENA_DE_MYSQL

10. Sustituya root y SU_CONTRASENA_DE_MYSQL por el mismo usuario y
    contrasena que utiliza para ingresar a MySQL Workbench. Guarde el
    archivo y confirme que su nombre no termine en .txt.

IMPORTANTE: schema.sql no puede crear database.properties porque el
usuario y la contrasena de MySQL son diferentes en cada computadora.

EJECUTAR DESDE NETBEANS
-----------------------
1. Presione Clean and Build Project.
2. Cuando aparezca BUILD SUCCESSFUL, presione Run Project.
3. La aplicacion inicia el servidor local en el puerto 5050 y luego
   muestra la ventana de ingreso.

EJECUTAR EL PAQUETE COMPILADO
-----------------------------
1. Utilice la misma carpeta FidnessRutinas extraida del ZIP completo.
2. Complete primero todos los pasos de la seccion PREPARAR MYSQL.
3. Abra una terminal en la carpeta FidnessRutinas. Es la carpeta que
   contiene dist, database, nbproject y src.
4. Ejecute:

   java -jar dist/FidnessRutinas.jar

FUNCIONES PRINCIPALES
---------------------
- Consultar y filtrar ejercicios.
- Ver el detalle de cada ejercicio.
- Agregar y eliminar ejercicios de la rutina.
- Exportar el resumen de la rutina a un archivo TXT.
- Registrar ejercicios con el usuario administrador.
- Conservar el catalogo y las rutinas en MySQL.

NOTAS
-----
- El conector MySQL ya se incluye en lib y dist/lib.
- La aplicacion crea los datos iniciales si las tablas estan vacias.
- Las credenciales privadas de MySQL no se incluyen en el repositorio.
- Si el puerto 5050 esta ocupado, cierre la otra instancia antes de iniciar.
